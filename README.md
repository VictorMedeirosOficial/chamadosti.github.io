Preparado para integração com a sua DB no computador através do GitHub.   🚀 Como Integrar na sua DB do Computador através do GitHubPasso 1: Subir o Projeto para o seu Repositório no GitHubAbra o terminal na pasta do projeto e execute:   Bashgit init

Passo 2: Criar / Importar a Tabela na sua DB Local (MySQL / MariaDB / XAMPP)Você tem duas formas super rápidas:   Forma Automática (Node.js): Configure o arquivo .env com o nome da sua database (DB_NAME=helpdesk_ti, DB_USER=root, DB_PASSWORD=) e rode npm install e node server.js. O servidor cria a database e as tabelas automaticamente!   Forma Manual (.SQL): Importe o arquivo database/database.sql (ou clique no botão "💾 Baixar Arquivo .SQL p/ Meu PC" dentro do próprio sistema) no seu phpMyAdmin / MySQL Workbench / DBeaver.   Passo 3: Conectar o Sistema (GitHub Pages ou Local) à DB do seu ComputadorNo seu computador onde está o banco de dados, inicie a ponte local executando iniciar_localhost_node.bat (ou node server.js).   O server.js já vem configurado com o cabeçalho Access-Control-Allow-Private-Network: true, permitindo que mesmo o site aberto pelo GitHub Pages ([https://seu-usuario.github.io/](https://seu-usuario.github.io/)...) envie e carregue dados diretamente de http://localhost:3000/api!   No topo do sistema, clique em "🐙 GitHub + Minha DB", confirme o nome da sua Database e clique em "🔌 Testar Conexão com Minha DB" ou "🔄 Sincronizar Chamados com Minha DB".
